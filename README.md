# AccessOS-Development-Linux-Distribution
A Linux distribution focused on accessibility and assistive technologies.

## About

AccessOS is a Debian-based Linux project designed to improve computer accessibility.

## Features

- KDE Plasma desktop environment
- Improved readability
- Accessibility tools
- Assistive technology experiments
- Open-source development

## Technologies

- Linux
- Debian
- Python
- GTK
- OpenCV
- MediaPipe

## Status

In development

## Goals

- Create an accessible Linux environment
- Develop assistive tools
- Improve computer usage for people with disabilities
